# Решения и ограничения

- Все постановщики равноправны и управляют всеми объектами и задачами.
- Исполнитель меняет только статус назначенной ему задачи. После переназначения доступ к задаче и её истории получает новый исполнитель.
- Постановщик редактирует поля и исполнителя в любом статусе. Это не сбрасывает статус; автор и дата создания неизменны.
- Удаление логическое. Удалённый объект скрывает все его задачи. История сохраняется; восстановления через интерфейс нет.
- Создание фиксируется переходом из пустого статуса в «Новая». Имя автора события сохраняется в истории, поэтому исполнителю не нужен доступ к чужим профилям.
- История содержит только смены статусов. Аудит изменения описания и назначения не входит в ТЗ.
- Реализация рассчитана на небольшой объём демоданных: без пагинации, поиска и realtime. При сохранении данные перечитываются.
- Нет регистрации, управления пользователями, вложений, уведомлений, видео и отдельного backend.
- Загруженные ранее данные могут оставаться на экране прежнего исполнителя до обновления; дальнейшие запросы база отклонит. При выходе/смене аккаунта состояние очищается.
- Исходники опубликованы в GitHub: https://github.com/falkomerr/objects-tasks-crm. Приложение работает локально; размещение сайта и отправка в hh.ru не выполнялись.
