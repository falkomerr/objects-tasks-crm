# Как работает система

«Контур» помогает руководителю распределять работы по стройкам и принимать результат. У каждого объекта есть название, адрес и список задач. Руководитель создаёт задачу и выбирает исполнителя. Исполнитель берёт работу, затем отправляет её на проверку. Руководитель принимает результат или возвращает задачу с обязательным объяснением, что исправить.

Исполнитель видит только свои задачи и стройки, где они находятся. Задачи других работников на той же стройке ему недоступны. Он не может назначить себя руководителем, переписать описание, сменить исполнителя, принять свою работу или удалить записи. Эти ограничения проверяет сама база данных, поэтому обход интерфейса не даёт дополнительных прав.

Каждый переход сохраняет имя пользователя, время, старый и новый статус, а также комментарий. Приложение не позволяет подделывать или исправлять историю. Одновременное нажатие кнопки не создаёт две одинаковые записи. Если руководитель меняет исполнителя, прежний работник сразу теряет доступ при последующих запросах.

Удаление скрывает объект или задачу из рабочих списков, сохраняя историю в базе. Новые пользователи не могут зарегистрироваться самостоятельно. Доступ выдаёт администратор. Демонстрационная версия доступна по ссылке из README, тестовые доступы передаются отдельно.
